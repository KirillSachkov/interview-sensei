Прототипы UI версии 1

Одноразовые макеты для тикета #3. Данные выдуманы, кнопки почти ничего не делают. Внизу каждого макета — переключатель вариантов, ◐ — тёмная тема.

A. Доска
Холст с целями-ветками и картой тем. Сессия открывается боковой панелью справа, Side thread — второй колонкой рядом. B. Рабочее место
Сессия в центре: чат с агентом слева, холст с карточками вопросов, прогресс справа. Доска — вкладка-матрица «темы × цели». C. Фокус
Один вопрос на экране, чат свёрнут в полоску внизу, Side thread — выдвижная панель. Прогресс — отдельный спокойный экран.

Подробности и вопросы для выбора — в README.ru.md.

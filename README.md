# Interview Sensei

Локальная подготовка к техническим собеседованиям с агентом, которым вы уже пользуетесь.

Статус: начало проекта. В репозитории пока есть только процесс разработки (harness), приложения ещё нет.

## Идея

Вы открываете приложение и проходите мок-собеседование. Его ведёт ваш агент: Claude Code, Codex или другой.
Приложение хранит вопросы, ответы и прогресс по темам. Новая сессия продолжает подготовку, а не начинает с нуля.

Первая версия открыта и работает локально. Свой LLM-клиент, ключи и аккаунты ей не нужны.
Границы версии описаны в [docs/requirements.ru.md](docs/requirements.ru.md).

## Как идёт разработка

Проект разрабатывают агенты по процессу из [agent-harness](https://github.com/KirillSachkov/agent-harness):

1. Обсуждение и issue. Полная spec нужна по сложности задачи.
2. Владелец явно запускает `implement` или `implement-spec`.
3. Работа в отдельном worktree, проверки, независимое Standards и Spec review.
4. `ship` готовит PR и ждёт CI. Владелец принимает результат и разрешает merge.

[Карта процесса](docs/process.ru.md) описывает шаги подробно. Правила агента находятся в [AGENTS.md](AGENTS.md).

# Domain guidance

Before domain design or exploration, read `DOMAIN.md` for canonical terms.
Read relevant ADRs under `docs/adr/` when they exist.
This repository currently has one context and no required ADR directory.
Use `domain-modeling` for active glossary and ADR work.

The glossary is root `DOMAIN.md`. If multiple contexts are introduced by an agreed change, `DOMAIN-MAP.md` maps their glossaries and ADRs. ADRs use `docs/adr/NNNN-slug.md`, with sequential numbers; create the directory only for the first agreed ADR.

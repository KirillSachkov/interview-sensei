Агент (Codex): Вымышленный транскрипт технического интервью. Интервьюер: Как безопасно прочитать поле у unknown? Кандидат: Сначала проверю null и typeof object, затем наличие поля и тип его значения. Сделаю type guard либо валидатор схемы. Приведение as само ничего не проверяет во время выполнения. Например, тело HTTP-запроса проверяю до передачи в бизнес-логику. Интервьюер: Как избежать двойной записи платежа при повторе запроса? Кандидат: Клиент передаёт idempotency key. Сервер закрепляет ключ уникальным ограничением и атомарно сохраняет результат вместе с изменением. Повтор с тем же содержимым возвращает сохранённый результат; другой payload с тем же ключом отклоняется. Для внешней платёжной системы тот же ключ передаю провайдеру, локальная транзакция внешнюю операцию не откатывает.

# 0001. Данные принадлежат модулям одного бэкенда

Для первого выпуска выбран один бэкенд с шестью модулями. «Цели и сценарии» владеет подтверждёнными целями и ожидаемыми этапами, «Материалы» отвечает за источники и доступ, «Банк вопросов» хранит вопросы и критерии. «Проведение мока» ведёт конкретную встречу, «Прогресс» хранит попытки и рассчитывает готовность, «Выполнение агента» вызывает модели и инструменты.

Настройка цели и интервью используют общий механизм выполнения со своими инструкциями и разрешёнными действиями. Права и допустимость изменения проверяет владелец данных. Так смена модели или режима диалога сохраняет одну точку проверки для каждой операции.

## English

The first release uses a single backend with six modules. Goals and Scenarios owns confirmed goals and expected stages. Materials owns sources and access. The Question Bank stores questions and assessment criteria. Mock Interview Conduct manages an individual meeting, Progress owns attempts and calculates readiness, and Agent Execution invokes models and tools.

Goal setup and interviews share the execution mechanism, with their own instructions and permitted actions. The module that owns the data checks access and whether a change is allowed. This keeps the same check in place when the model or conversation mode changes.

# Owner gate conditions

Only the owner edits this file. `owner-gate` applies the first status that matches.

| Status | When | What follows |
| --- | --- | --- |
| Needs attention | The change departs from the agreed task, or carries a risk only the owner can weigh: access, money, personal data, an irreversible change, a visible change without an approved design. | Delivery waits for the owner's answers. |
| Needs decision | The task reserved a decision for the owner and the result is ready to judge. | Delivery waits for that decision. |
| No owner needed | The change follows the task, any required verification passed and nothing is reserved. | The agent may merge. |

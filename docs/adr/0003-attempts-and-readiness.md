# 0003. Общая попытка служит основанием для оценки в нескольких целях

Один и тот же ответ может показать умение, которое требуется для разных позиций. «Прогресс» хранит попытку в истории кандидата один раз и оценивает готовность с учётом требований каждой цели и этапа. После исправления или удаления попытки сервис пересчитывает затронутые оценки, включая вывод «пока нет данных», если других свидетельств больше нет.

Попытка связана с фактически заданной версией вопроса, проверяемым умением и действовавшим критерием. Например, если в банк добавили требование объяснить производительность запроса, кандидат по-прежнему может открыть прежнюю формулировку и понять оценку своего ответа. Изменённое требование применяется к новой версии.

## English

One answer can demonstrate a skill needed for different positions. Progress stores the attempt once in the candidate’s history and assesses readiness against each goal and stage. Correcting or deleting the attempt updates the affected assessments. When no evidence remains, the assessment shows that no data is available yet.

An attempt refers to the question version actually asked, the skill it assessed and the criterion in effect. If the bank later adds a requirement to explain query performance, the candidate can still open the original question and see how the answer was assessed. The new requirement applies to the new version.
